# The 340B Swap

On January 1, 2027, Medicare starts paying for drugs that hospitals buy through the 340B discount program at ASP minus 28%,
down from ASP plus 6%, and spends the savings, about $4.65 billion, raising every outpatient hospital's other payments by 7.5%.
This site shows, hospital by hospital, which side of that trade each hospital lands on, and why.
